# 構成
- お題：{お題}
- 最低1600字、発言は最低20回（上限はない）
- 発言の流れは、次の順にする
  1. めたんが、直前の行を受けてお題に移る振りをする。振りは冒頭の1回だけにし、前のお題のまとめやお礼は言わない。前のお題を下げる言い方（「今度はもっと奥深い」など）をしない。お題の名前で切り出し、何番目のお題かを表す言い方はしない
  2. ずんだもんの基本説明
  3. つむぎの質問と、ずんだもんの回答の往復。めたんは要約や短いツッコミで入る
  4. 早口の場面（下の手順どおり）
  5. 最後の発言は、つむぎの締めの一言。そのあとに誰の発言も書かない。めたんは、締めの一言を求める振りをしない（つむぎが自分から締める）
- 素材の "pitfalls" と "surprising" を、話の流れの中で自然に1つずつ入れる。素材の項目の名前や、それを日本語に言い換えた見出しの言葉は台詞にしない。前の話とのつながりで切り出す
- 早口の場面は、次の4つの発言を、この順に続けて書く
  1. ずんだもんが、素材の "zunda_rant" を使って、うっとり早口で語る（5文以上。それまでに話していない新しい話にする）
  2. その直後の発言で、つむぎかめたんがツッコんで止める（ツッコミは、早口の発言の後にだけ入れる）
  3. ずんだもんが我に返って、一言でまとめる
  4. つむぎかめたんが、本題に戻る質問や相づちをする
- ずんだもんは自分で語りを止めない。早口でツッコまれた直後以外では、我に返る言い方をしない
- 早口の場面でも、一文ずつ「〜のだ」で終える。「…」で切りっぱなしにしない。意味の通らない文や、同じ意味の言葉を並べただけの文を書かない
- 文字数が足りない場合は、素材の範囲で具体例・使用場面・つむぎの質問を足す。同じ内容の言い換えや一般論の繰り返しで水増ししない
- つむぎの締めの一言は、このお題で話した内容から、身近なものにつながる前向きな感想にする。「〜してみたい」「〜してみようかな」で終わらせない。ほかのお題の締めと同じ言い回しにしない

# 守ること（NGリスト）
- 素材にない数値・価格・歴史・因果関係（「〜だから〜が増えた」など）を足さない
- 仕様は、素材に書かれた範囲で言う。素材にない「機種によって違う」「モデルによって違う」を足さない
- 素材の "uncertain" に入っている内容と、確認用の注記（確かめられていない、断定できない など）は台詞にしない
- たとえ話で金額や数量を出すときは、現実的な範囲にし、計算を合わせる（「百円と千円で二倍」のような食い違いをしない）
- つむぎは専門用語を自分から使わない
- 誰も、つむぎの家族・家・持ち物・職場・過去の体験を話題にしない（つむぎ自身も話さない）
- ずんだもんは、自分の体験談（壊した、持っている、置いている など）を作らない
- 「〜がないと〜は動かない」「〜なしには不可能」のような言い過ぎをしない
- 同じ人が2回続けて話さない
- めたんの発言は2文まで。「では」で始まる発言はこのセクションで1回まで。受けの言い回し（「〜わけですね」など）を繰り返さない。直前の自分の発言と同じ言い回しを使わない
- ずんだもんの「でもね、」「だからね、」のような「〜ね、」は、このセクションで2回まで
- 「いい質問」はこのセクションで1回まで。つむぎが実際に質問した直後だけ使う
- 質問には必ず答える。答えないまま次の話題に移らない。つむぎが用語を聞き返したら（「〇〇って何？」）、ずんだもんは次の発言でその用語の意味を答える。つむぎが「もっと知りたい」と頼んだら、次の発言でその話をする
- 前に言ったことと矛盾させない。予告した話は必ずする
- 聴き手が知らない略語は、初めて出たときに、ずんだもんが正式名か意味を添える。よく知られた略語（番組の項を参照）はそのまま使う。正式名を言うのはずんだもんだけにする
- 新しく出た専門用語は、初めて出た発言か、つむぎが聞き返した次の発言で、ずんだもんが一言で意味を説明する
- 同じ言葉の表記を混ぜない（カタカナとひらがな、長音の有無）
