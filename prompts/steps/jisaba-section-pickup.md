# 構成
- 最低1600字、発言は最低20回（上限はない）
- 素材の "points" の3つを、1つずつ順に扱う。1つの要点ごとに、次の順に書く
  1. めたんが、記事に書いてあることを紹介する（2文まで。このコーナーだけは、めたんが記事の内容を説明してよい）
  2. つむぎが素朴な疑問や驚きでリアクションする
  3. ずんだもんが、自分の意見・用語の説明・関連する話をする
  4. 必要なら、つむぎの質問とずんだもんの答えを1〜2往復足す
- 記事の内容を伝える発言は、すべてめたんがする。ずんだもんは、めたんが紹介した内容への意見・用語の説明・関連する話だけをし、記事の内容を伝える言い方（記事によると、記事では、筆者は など）を使わない
- 用語の説明は、めたんではなくずんだもんがする。つむぎが用語を聞き返したら、次の発言でずんだもんが答える（めたんが取り次がない）
- 聴き手が知らない略語は、初めて出たときに、ずんだもんが正式名か意味を添える。よく知られた略語はそのまま使う。型番は素材の "readings" の読みで言う
- ずんだもんは聞き役にならない。記事の内容を知らない側に回らない
- 早口の場面は、2つ目の要点の3.で1回だけ入れ、次の3つの発言をこの順に続けて書く
  1. ずんだもんが、うっとり早口で語る（5文以上）
  2. その直後の発言で、つむぎかめたんがツッコんで止める
  3. ずんだもんが我に返って、一言でまとめる
- ずんだもんは自分で語りを止めない。早口でツッコまれた直後以外では、我に返る言い方をしない
- 「記事の新旧」が「古い記事」のときだけ、めたんが「○年の記事なので、今は事情が変わっている部分もあるかもしれませんわね」と一言添える。「新しい記事」のときは、記事の日付に触れない
- 最後の発言はつむぎにし、記事の話を身近なものにつなげる前向きな一言にする。そのあとに誰の発言も書かない。めたんは、締めの一言を求める振りをしない

# 記事の内容と意見を分ける（重要）
- 記事に書いてあること（"points" と "details" の内容）は、めたんが「記事によると」「著者の方は」のように、記事の内容だと分かる形で話す
- 記事に書いていない解釈・推測・一般論は、「ボクは〜だと思うのだ」「〜なのかしら」のように、話している人の意見だと分かる形で話す。記事の主張として語らない
- 素材にない記事の内容（デザインの細部、著者の意図、作業の手順、エラーの名前など）を作らない
- 同じ要点を、言い方を変えて2回以上繰り返さない
- 記事の文章を引用するときは、記号（〜、ー の連続など）を取り除いて読める形にする

# 守ること
- お礼の言葉（「お聴きいただきありがとうございます」など）やコーナーの締めの挨拶は言わない（このあとに記事の案内とエンディングが続くため）
- 誰も、つむぎの家族・家・持ち物・自分のブログなどを話題にしない（つむぎ自身も話さない）
- 同じ人が2回続けて話さない
- めたんの発言は2文まで。「では」で始まる発言はこのコーナーで1回まで
- 「いい質問」はこのコーナーで1回まで。つむぎが実際に質問した直後だけ使う
- 素材にない数値・歴史・因果関係を足さない
