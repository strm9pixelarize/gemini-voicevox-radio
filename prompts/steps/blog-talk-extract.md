# ブログトーク素材抽出

ブログ記事から、座談会番組「ブログトーク」の素材を作ります。

## やること
記事を読み、次のJSONだけを出力してください。前置き・説明・コードフェンス以外の文は書かないこと。

```json
{
  "summary": "記事のあらまし（200〜300字。何があって、どうなったか）",
  "mountains": [
    {"title": "深掘りの山1のタイトル（短く）", "detail": "その山で話すべき内容。記事の具体的なエピソード・数字・経緯を、事実のまま詳しく（400〜600字）"},
    {"title": "山2のタイトル", "detail": "同上"},
    {"title": "山3のタイトル", "detail": "同上"}
  ],
  "readings": [
    {"term": "記事に出てくる英字の単語・略語", "kana": "カタカナ読み"}
  ]
}
```

## ルール
- 山は必ず3つ。記事の流れに沿って、話が膨らむポイントを選ぶ（単なる見出しの分割にしない）
- detail には記事に書かれていない事実を足さない
- readings は、読み上げで詰まりそうな英字語だけ（一般的な日本語は入れない）
